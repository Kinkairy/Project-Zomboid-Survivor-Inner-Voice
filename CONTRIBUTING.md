# Contributing

Please open an issue before making a substantial behavior, protocol, state
coverage, or localization change. Preserve vanilla state semantics, keep hidden
infection excluded, and describe how each changed scheduler or rendering path
was verified.

Player-facing lines should read as direct self-talk rather than status reports.
Severity must remain understandable without relying on color alone, and a line
must not invent a disease, injury, history, or character background that the
game state does not establish.

Do not commit credentials, server addresses, private logs, local Workshop
publisher paths, generated caches, internal test harnesses, AI-platform raw
outputs, or third-party artwork.
